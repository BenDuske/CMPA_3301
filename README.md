# CMPA 3301 — Coursework Repository

**Benjamin Duske** · Texas Tech University · Late Fall 2026 (Oct 19 – Dec 10)

This is the home base for my work in **CMPA 3301**, an asynchronous online course on
project management for the "unofficial" project manager and the web skills that go with
it. The idea behind the class is a hybrid one: pair the generalist mindset from *Range*
with the practical framework in *Project Management for the Unofficial Project Manager*,
then actually build something with HTML, CSS, Markdown, and Git.

This repo is my single source of truth for everything I turn in. I keep the full course
materials, lecture PDFs, and readings on my own machine; what lives here is the work —
the deliverables.

---

## How this repo is organized

The course runs in eight weeks. Each week has its own folder, and inside each week I keep
two things:

- **`Assignment/`** — the raw course material I'm working *from* (lectures, readings,
  prompts). **Not tracked in Git.** This stays local so the repo stays clean and focused
  on what I produce.
- **`Deliverables/`** — the finished work I'm submitting. **This is what Git tracks.**

```
CMPA_3301/
├── Week_1/  ├── Assignment/ (local)   └── Deliverables/ (tracked)
├── Week_2/  ├── Assignment/ (local)   └── Deliverables/ (tracked)
├── Week_3/  ├── Assignment/ (local)   └── Deliverables/ (tracked)
├── Week_4/  ...
├── Week_5/
├── Week_6/
├── Week_7/
└── Week_8/
```

The course `Info/` and `Resources/` folders (syllabus, schedule, textbook PDFs) are also
kept out of version control. They're reference material, not deliverables.

## Week-by-week focus

- **Week 1 — The Value of Range & the Hybrid Mindset.** Kind vs. wicked learning
  environments, match quality, and the role of the unofficial PM. *(Assignment 01: Personal
  Project Charter.)*
- **Week 2 — The Project Economy & GitHub.** Principles of project success, informal
  authority, and getting set up with Git/GitHub Desktop.
- **Week 3 — Structuring Digital Information.** Markdown, semantic HTML, and project
  scoping. *(Project 01 due.)*
- **Week 4 — Presenting Digital Information.** CSS, the box model, and planning for risk.
  *(Assignment 02: Styling Your Introduction.)*
- **Week 5 — Collaborative Workflows.** Git, branches, pull requests, and GitHub as a
  collaboration hub. *(Project 02 due.)*
- **Week 6 — Managing Active Projects.** Tracking progress, scope discovery vs. scope
  creep, cadence of accountability. *(Assignment 03: Final Project Scope Statement.)*
- **Week 7 — Synthesis & Professional Practice.** Documenting, closing projects, and the
  retrospective. *(Assignment 04: Peer Review of Project Scopes.)*
- **Week 8 — Final submission.** No new topics — finish and ship Project 03.
